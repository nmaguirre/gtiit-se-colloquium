# GTIIT Colloquium on the Foundations of Modern Software Engineering

Website for the GTIIT Colloquium on the Foundations of Modern Software Engineering, taking place October 30 – November 1, 2026, at GTIIT, Shantou, Guangdong, China. Pre-colloquium tutorials: October 23–24, 2026.

## Editing the site

All content lives in `index.html`. Open it in any text editor to update:

- **Speakers** — find the `<section id="speakers">` block and edit or add `speaker-card` entries.
- **Program** — find `<section id="program">` and replace the "to be announced" placeholders.
- **Tutorials** — find `<section id="tutorials">` for pre-colloquium content.
- **Contact emails** — search for `mailto:` and update both addresses.

## Deployment

This site is hosted via [GitHub Pages](https://pages.github.com/). Any push to the `main` branch is automatically deployed.
